# USBra — Dependencies

Deliverable #8. The MVP host has **zero third-party Rust crates** (std only) —
a deliberate constraint so the core builds anywhere, offline, in seconds.

## Host (implemented, M0–M5)

| Dep | Version | Why | Install |
|---|---|---|---|
| Rust toolchain | ≥ 1.75 (tested 1.90) | build | `rustup` or `apt install cargo` |
| adb (host side) | platform-tools ≥ 28 | USB tunnel + APK install | `sudo apt install adb` (Ubuntu 24.04 ships 34.x) |
| bash | any | scripts | system |

Optional for udev rules so non-root adb sees the phone:
`sudo apt install android-sdk-platform-tools-common` (provides
`/lib/udev/rules.d/51-android.rules`), or use the Google
[platform-tools](https://developer.android.com/tools/releases/platform-tools)
bundle.

## Host (M6, GNOME backend)

| Dep | Version | Why |
|---|---|---|
| `zbus` crate | 5.x | session-bus D-Bus client for `org.gnome.Mutter.ScreenCast` (feature `gnome`) |
| `pollster` / `async-io` / `futures-lite` | — | block on zbus futures from the sync host |
| `python3-gi`, `gstreamer1.0-tools`, `gstreamer1.0-pipewire` | — | M6a probe + `scripts/m6-pw-grab.py` frame consumer for `--source gnome` |
| `zstd` crate | 0.13.x | M7 compression (binds libzstd or bundles) |

Build / run the GNOME path:

```bash
sudo apt install -y python3-gi gstreamer1.0-tools gstreamer1.0-pipewire
cargo run -p usbra-host --features gnome -- --probe-gnome --hold 20
scripts/run-gnome-demo.sh   # --source gnome + stats + frame-ack
```

`pipewire` / `libpipewire-0.3-dev` remain optional until we replace the GStreamer
grabber with a native damage-aware consumer.

No display manager changes, no kernel modules, no root for the M6 path.

## Host (M6b, evdi fallback backend — optional)

| Dep | Why |
|---|---|
| `build-essential`, `cmake`, `dkms`, `linux-headers-$(uname -r)` | build evdi |
| evdi (git, GPLv2 kernel module + LGPL-2.1 libevdi) | virtual DRM card |
| `libdrm-dev` | DRM ioctl headers |

DisplayLink verifies evdi against kernels up to 6.15; expect occasional patch
lag on very fresh kernels (risk entry in `docs/08-risks.md`).

## Android client

| Dep | Version | Why |
|---|---|---|
| JDK | 17 (Android Studio's bundled JDK is fine; JDK 25 is too new for AGP) | build |
| Android Gradle Plugin | 8.5.2 | build system |
| Kotlin | 2.0.20 | app language |
| Gradle | ≥ 8.7 (wrapper generated by Android Studio) | build |
| Android SDK platform + build-tools | 34 | compileSdk/targetSdk 34 |
| Device | Android ≥ 8.0 (minSdk 26), GLES 2.0+ | runtime |

App dependencies: **none** (no AndroidX, no Compose — plain `Activity` +
`GLSurfaceView`; keeps the APK tiny and the build hermetic).

Runtime requirement on device: **USB debugging enabled** (Developer options)
until the AOAP transport lands (M11).
